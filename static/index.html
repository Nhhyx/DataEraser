→ Have I Been Pwned - fuites de données
Vérifiez si vos emails ont été compromis dans des fuites de données connues.
🚨 Si des fuites sont détectées - Actions prioritaires :
  • 1. Changer immédiatement le mot de passe du ou des comptes compromis
  • 2. Changer l'adresse email associée au compte touché si possible, ou créer un alias
  • 3. Changer TOUS les mots de passe des autres comptes où vous avez réutilisé le même mot de passe - les attaquants testent automatiquement les mots de passe volés sur tous les services connus (credential stuffing)
  • 4. Activer la double authentification (2FA) sur tous vos comptes importants (email, banque, réseaux sociaux)
  • 5. Utiliser un gestionnaire de mots de passe : Bitwarden (open-source, gratuit) ou KeePassXC (100% local)
  • 6. Surveiller vos comptes bancaires et emails pour détecter toute activité suspecte

→ Identifiant publicitaire - trouver, réinitialiser, refuser

Chaque appareil possède un identifiant unique utilisé par les apps et réseaux sociaux pour vous cibler entre plateformes - sans avoir besoin de votre nom.

Ce sont des données de suivi très précises, qui peuvent révéler vos habitudes, centres d'intérêt, déplacements…
📱 iPhone / iPad (iOS - IDFA)
▼
Trouver l'IDFA :
Réglages → Confidentialité et sécurité → Suivi → l'ID n'est pas affiché directement par Apple. Utilisez une app tierce comme My IDFA (App Store) pour le lire.

Désactiver le suivi cross-apps :
Réglages → Confidentialité et sécurité → Suivi → désactiver "Autoriser les demandes de suivi" → toutes les apps ne peuvent plus accéder à votre IDFA.

Réinitialiser l'identifiant :
Réglages → Confidentialité et sécurité → Publicité Apple → "Réinitialiser l'identifiant publicitaire" → un nouvel ID est généré, l'ancien devient inutilisable.

Refuser le ciblage pub Apple :
Réglages → Confidentialité et sécurité → Publicité Apple → activer "Publicités personnalisées" sur OFF.
→ Support Apple (suivi)
🤖 Android (GAID / AAID)
▼
Trouver le GAID :
Paramètres → Google → Annonces → votre identifiant publicitaire est affiché en clair.

Supprimer l'identifiant (Android 12+) :
Paramètres → Google → Annonces → "Supprimer l'identifiant publicitaire" → confirmez. L'ID est remplacé par un identifiant nul non utilisable pour le ciblage.

Réinitialiser seulement :
Paramètres → Google → Annonces → "Réinitialiser l'identifiant publicitaire" → un nouvel ID est généré.

Désactiver la personnalisation :
Paramètres → Google → Annonces → désactiver "Personnalisation des annonces".

Note : le chemin peut varier selon le fabricant (Samsung, Xiaomi…). Cherchez "Annonces" dans la barre de recherche des paramètres.
→ Documentation Google (GAID)
🪟 Windows 10 / 11
▼
Trouver et désactiver l'ID pub :
Paramètres → Confidentialité et sécurité → Général → désactiver "Autoriser les applications d'utiliser mon ID de publicité".

Autres réglages recommandés sur la même page :
- Désactiver "Me proposer des contenus en fonction de ma liste de langues"
- Désactiver "Me montrer des suggestions de contenu dans l'application Paramètres"

Réinitialiser :
Il n'y a pas de bouton "réinitialiser" explicite sous Windows. Désactiver l'option suffit - Windows cesse de transmettre l'ID aux apps.
→ Ouvrir Paramètres → Confidentialité → Général
🍎 macOS
▼
ID publicitaire macOS :
Apple n'expose pas d'identifiant publicitaire aux apps tierces sur macOS (contrairement à iOS). Les apps Mac Store ne peuvent pas accéder à un IDFA équivalent.

Publicités personnalisées Apple :
Préférences Système → Identifiant Apple → Médias et achats → "Publicités personnalisées" → désactiver.

Safari - protection contre le tracking :
Safari → Préférences → Confidentialité → cocher "Empêcher le suivi inter-sites" et "Masquer l'adresse IP".
→ Support Apple (confidentialité Mac)
📺 Smart TV / Autres appareils
▼
Smart TV (Samsung, LG, Sony…) :
Chaque fabricant a son propre ID de suivi. Cherchez dans les paramètres de la TV : Confidentialité → Publicités → "Réinitialiser l'ID" ou "Limiter le suivi pub".

Amazon Fire TV :
Paramètres → Préférences → Confidentialité → "Réinitialiser l'identifiant publicitaire".

Chromecast / Google TV :
Paramètres → Confidentialité → Annonces → "Réinitialiser l'ID publicitaire".
💡 Même après réinitialisation, les données déjà collectées sous l'ancien ID restent chez les annonceurs. Vous pouvez demander leur suppression via les formulaires RGPD de chaque plateforme (Google Ads, Meta, etc.) en mentionnant l'ancien identifiant.

💡 Toujours refuser le tracking -"données de suivi/pistage"- d'absolument toutes les applications que vous téléchargez, ainsi que la personnalisation des données publicitaires. Et si possible l'accès à votre position exacte.
→ Refuser le ciblage pub sur chaque plateforme
